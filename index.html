Project Ideas

Ideas for putting C into practice. Open any idea to see how to start and what you could add later.

Rubik’s Cube Scramble Generator

Start by generating a random sequence of 3×3 cube moves using standard notation like R, U′, and F2. Avoid consecutive moves on the same face.

Try next: Add a solve timer and save your best times.

Student Marks Tracker

Enter marks and maximum scores for each subject, then calculate the overall percentage and identify the highest-scoring subject.

Try next: Save records to a CSV file and load them again.

Command-Line Quiz Game

Store multiple-choice questions in structs, check each answer, and show the final score.

Try next: Shuffle the questions and show a review of missed answers.

Tic-Tac-Toe

Use a 3×3 array for the board, check each move, and detect wins or draws in a two-player game.

Try next: Add a computer opponent that blocks winning moves.

Personal Expense Tracker

Record an amount, date, and category for each expense. Show the total spent by category.

Try next: Save expenses to a file and add monthly summaries.

Maze Solver

Read a maze from a text file and use breadth-first search to find a shortest path from the start to the exit.

Try next: Print the maze with the path marked and report the number of steps.
